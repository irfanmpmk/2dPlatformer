# Blade of the Wilds

A 2D pixel-art action platformer that runs in the browser. It is a single HTML file with no build step and no dependencies.

You play a sword-wielding hero crossing 9 stages: Forest, Riverbank, Jungle, Desert, Bandit Town, Misty Valley, Mountain Peaks, Volcano and Sky Kingdom. Each stage has its own enemies and ends with a boss fight.

## Play locally

Open `index.html` in any modern browser.

## Controls

| Action | Keyboard | Touch |
|---|---|---|
| Move | Arrow keys / A, D | ◀ ▶ |
| Jump (double jump in the air) | Z / W / Space | JUMP |
| Sword slash (3-hit combo) | X / J | SLASH |
| Sword wave (uses energy) | C / K | WAVE |
| Dash (invulnerable) | Shift / L | DASH |
| Pause / start | Enter / P / Esc | II / tap |

## Publish with GitHub Pages

Go to the repo's Settings, open Pages, and set the source to the `main` branch with the `/ (root)` folder. The game will then be live at `https://irfanmpmk.github.io/2dPlatformer/`.
